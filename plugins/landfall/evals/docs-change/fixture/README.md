# tidy

Sorts the files of a directory into sub-folders by type.

## Install

```sh
npm install --global tidy-dir
```

## Usage

```sh
tidy [options] <dir>
```

## Options

| Flag | Description |
|------|-------------|
| `--verbose` | Print every file as it is moved. |
| `--help` | Show usage and exit. |
